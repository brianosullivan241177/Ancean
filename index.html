FPL Deadline Tracker

FPL Deadline Tracker is an app to help you with the deadlines for Fantasy Premier League. It will show the next two deadline dates and times, based on GMT. There is also an option to add a timer to the lock screen, this is only available 48 hours before the deadline. There is also a link to the Fantasy Premier League website. This is my first app.
